# Server Geraldo

Modpack do Kaue (Minecraft 1.21.1, NeoForge 21.1.251) no formato packwiz.
A instância do Prism dos amigos roda o packwiz-installer antes de abrir o jogo e atualiza sozinha.

## Créditos

`mods/CobblemonExtras-neoforge-1.5.0.jar` é uma versão ajustada do CobblemonExtras de Xwaffle1 (licença MIT, https://github.com/Xwaffle1/CobblemonExtras). O pacote `org.jetbrains.annotations` foi retirado do jar para evitar um conflito de módulos com outros mods.
